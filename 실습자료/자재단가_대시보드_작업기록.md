- 대상 데이터: `자재단가_2022-2024.csv`
- 산출물: `자재단가_대시보드.html`

- 목적: CSV 파일을 기반으로 브라우저에서 바로 열 수 있는 단일 페이지 HTML 대시보드 생성

## 대시보드 구성

- 필터
  - 시작월
  - 종료월
  - 카테고리
  - 자재명
  - 공급업체
- KPI
  - 평균 단가
  - 총 발주수량
  - 최고 단가 자재
  - 단가 변동폭 최대 자재
- 차트
  - 월별 평균 단가 추이
  - 카테고리별 평균 단가
  - 공급업체별 발주수량
  - 자재별 단가 변동폭 Top 10
- 상세 테이블
  - 필터링된 데이터를 단가 높은 순으로 표시

## 구현 방식

- CSV 302행 전체를 HTML 내부 JavaScript 데이터로 내장했다.
- 별도 서버 없이 `자재단가_대시보드.html` 파일을 브라우저에서 직접 열 수 있다.
- 차트 렌더링은 Chart.js CDN을 사용한다.
- 필터가 변경되면 KPI, 차트, 상세 테이블이 즉시 다시 계산된다.

## 검증 결과

- 원본 CSV 행 수: 302
- HTML 내장 데이터 행 수: 302
- 평균 단가: 189,833원
- 총 발주수량: 79,540
- 원본 CSV와 HTML 내장 데이터의 핵심 집계가 일치함을 확인했다.

## 참고 사항

- Chart.js CDN을 사용하므로 차트가 표시되려면 인터넷 연결이 필요하다.
- 인터넷 없이 실행해야 하면 Chart.js 파일을 로컬에 저장하고 HTML에서 로컬 파일을 참조하도록 변경하면 된다.
- 브라우저 자동화 검증은 로컬 샌드박스 오류로 완료하지 못했지만, 파일 구조와 데이터 집계 검증은 완료했다.
