이미 준비된 경우 해당 단계는 건너뛰세요.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1. Python 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 웹 브라우저에서 https://python.org/downloads 접속
2. "Download Python 3.x.x" 버튼 클릭하여 설치 파일 다운로드
3. 설치 파일 실행 시 반드시 "Add Python to PATH" 체크 후 Install Now
4. 설치 완료 후 명령 프롬프트(cmd)에서 확인:
   python --version


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2. VS Code 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. https://code.visualstudio.com 에서 Windows 버전 다운로드
2. 설치 시 "PATH에 추가" 옵션 체크
3. VS Code 실행 후 확장(Extensions, Ctrl+Shift+X) → "Python" 검색 → Microsoft 공식 확장 설치


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 3. 작업 폴더 준비
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 바탕화면에 "AI실습" 폴더 생성
2. 실습자료 CSV 파일을 해당 폴더에 복사
3. VS Code 메뉴 → 파일 → 폴더 열기 → "AI실습" 선택


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 4. 필수 라이브러리 설치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

명령 프롬프트(Win+R → cmd)에서 아래 명령어 입력 (최초 1회):

  pip install pandas openpyxl

설치 확인:
  python -c "import pandas; print(pandas.__version__)"


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 5. Python 스크립트 실행 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

VS Code 터미널(Ctrl+`) 또는 명령 프롬프트에서:

  python 파일명.py

예) python 장비_월간_집계.py

실행 후 같은 폴더에 결과 Excel 파일이 생성됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
자주 발생하는 오류
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

오류: ModuleNotFoundError: No module named 'pandas'
해결: pip install pandas openpyxl 재실행

오류: FileNotFoundError: 장비유지보수_2022-2024.csv
해결: CSV 파일과 .py 파일이 같은 폴더에 있는지 확인

오류: UnicodeDecodeError
해결: CSV 파일을 메모장으로 열어 UTF-8 인코딩으로 다시 저장

오류 메시지를 ChatGPT에 붙여넣고 "이 오류 해결해줘"라고 하면
대부분 즉시 수정 코드를 받을 수 있습니다.
