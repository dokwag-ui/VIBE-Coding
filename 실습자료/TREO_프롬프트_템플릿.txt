[T] 장비 유지보수 점검 현황을 한눈에 볼 수 있는 HTML 대시보드를 만들어줘.
    대상 사용자: LIG D&A 설비 관리 담당자

[R] 표시할 데이터:
    - KPI 카드: 전체 장비 수(24대), 점검 완료(18대), 점검 임박 30일 이내(4대), 기한 초과(2대)
    - 장비 목록 표: 장비ID, 장비명, 설치위치, 담당자, 최근점검일, 다음점검예정일, D-day
    - 샘플 데이터 10건 이상 포함 (D-day 음수·7 이하·30 이하·30 초과 케이스 모두 포함)

[E] 화면 구성:
    - 상단: "LIG D&A 장비 점검 현황" 제목 + 오늘 날짜 자동 표시
    - 중단: KPI 카드 4개 가로 배열
    - 하단: 장비 목록 표 (D-day 오름차순 정렬)
    - D-day 음수(기한 초과): 빨간 배경 강조
    - D-day 1~7: 주황 배경 강조
    - D-day 8~30: 노란 배경 강조
    - D-day 31 이상: 기본 흰색

[O] - 단일 HTML 파일 하나로 완성 (외부 파일 의존성 없이)
    - 한국어로 모든 텍스트 작성
    - 깔끔하고 전문적인 디자인 (Bootstrap 없이 순수 CSS)
    - 브라우저에서 바로 열리는 정적 파일
    - 코드 전체를 하나의 코드 블록으로 출력

주의: ChatGPT에 위 프롬프트를 입력하면 200~300줄 HTML 코드가 생성됩니다.
코드 블록을 전체 복사 → 메모장 붙여넣기 → 파일명 "장비점검_대시보드.html",
파일 형식 "모든 파일(*.*)", 인코딩 UTF-8 로 저장 → 더블클릭으로 브라우저 확인.

[T] 구매팀 담당자가 월별 자재 단가 변동 이상값을 모니터링하는 대시보드.
    목적: 전월 대비 20% 이상 단가 변동 자재를 즉시 식별하고 조치 우선순위 파악.

[R] 표시할 데이터:
    - KPI 카드: 전체 자재 수(30), 정상(22), 주의 10~20%(5), 이상 20% 초과(3)
    - 자재 목록 표 필드: 자재코드, 자재명, 전월단가(원), 당월단가(원), 변동률(%), 상태
    - 샘플 데이터 15건 (변동률 음수 포함, +5% ~ +35% 범위)
    - 단가는 천 단위 쉼표 포맷(예: 125,000원)으로 표시

    3. 자재 목록 표:

       - 주의(10% ~ 20%): 연한 주황 + "주의" 태그
       - 정상: 흰색 + "정상" 태그
    4. 표 하단: "이상값 발생 시 구매팀(내선 1234) 보고 필요" 안내 문구
